Product and service information

Bouncr

Bouncr is a Windows desktop workspace that helps creators produce original physics simulations and deliberately prepare each finished video for publishing.

What the service provides

The production workspace contains configurable simulation modes, recording controls, audio tools, and export workflows. Its Creator Dashboard adds video preview, technical validation, metadata review, creator choices, scheduling, transfer progress, and publishing status.

Simulation production

Create and record original ball and physics-based visuals with configurable scenes, timing, audio, and presentation.

Media review

Select a finished file, preview it, and check its technical properties before it enters the publishing queue.

Creator choices

Edit the caption, manually select an available privacy level, set interaction permissions, and provide required disclosures.

Local scheduling

Choose a time and explicitly approve the exact media and metadata. The desktop scheduler must remain running to start the transfer.

How account connection works

Bouncr opens TikTok's authorization page in the creator's browser. TikTok handles sign-in and consent; Bouncr does not request the creator's TikTok password. After approval, the Creator Dashboard identifies the connected account and requests only the permissions needed for the selected publishing workflow.

Supported publishing workflows

Depending on the available product configuration and account permissions, Bouncr can use Direct Post or transfer a draft to the creator's TikTok inbox. In inbox mode, the creator completes editing and publication inside TikTok. TikTok remains responsible for processing, moderation, and final availability.

System and operating requirements

  • A supported Windows computer running the Bouncr desktop application.
  • A creator-controlled TikTok account eligible for the requested publishing workflow.
  • A network connection when connecting an account, transferring media, and checking status.
  • The local Bouncr scheduler running at the selected transfer time.
  • A finished video that meets TikTok's current technical and content requirements.

Creator safeguards

Bouncr requires an explicit privacy selection and confirmation for the exact scheduled video. Comments, Duet, and Stitch are not enabled by default. Commercial-content, AI-content, and music declarations are presented when relevant. Queued jobs can be cancelled before transfer begins.

Availability and support

Creators can contact Bouncr Support for product availability, setup questions, account disconnection, or failed transfers. Bouncr is an independent service and is not affiliated with or endorsed by TikTok.
